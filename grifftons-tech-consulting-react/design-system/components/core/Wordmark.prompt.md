The identity mark — the name in type. There is no logo symbol in this brand.

```jsx
<Wordmark size={26} />
<Wordmark size={64} lockup role="Product Designer" />
<Wordmark variant="initials" size={20} tone="inverse" />
```

Set in Newsreader Medium with tight optical tracking (−0.035em above 40px, −0.02em below). `lockup` adds an uppercase Inter role line at 34% of the name size. Never enclose it in a badge, box or circle — the name stands alone on the page.
