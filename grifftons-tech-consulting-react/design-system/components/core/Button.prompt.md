Always fully round — never a rounded rectangle.

```jsx
<Button variant="primary" size="l" iconRight="→">Start a project</Button>
<Button variant="outline">Read the case study</Button>
<Button variant="link">See all writing</Button>
```

One primary per view. `accent` (saffron) is for the single loudest CTA on a page and never sits next to `primary`. `inverse` is the only variant used on the forest ground. Hover lifts 1px and darkens; there is no press-shrink.
